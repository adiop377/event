# Pride Patna Marathon 2027 (Patna Runs Together)

Official website for **Pride Patna Marathon 2027** — Patna's premier community distance-running event taking place on **14 Feb 2027** at **Gandhi Maidan, Patna**.

Rebuilt with **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

---

## 🏃 Features & Highlights

- **Hero & Countdown**:
  - Live flag-off countdown (Days, Hours, Minutes, Seconds) with direct "Add to Google Calendar" link.
  - Interactive "Watch promo" preview modal.
- **Race Categories**:
  - **5K Fun Run** (₹499)
  - **10K Challenge Run** (₹799)
  - **21.1K Half Marathon** (₹1,299)
  - **42.2K Full Marathon** (₹1,899)
- **Course Architecture**:
  - Interactive course switchers (5K, 10K, 21K, 42K).
  - SVG elevation profile chart with key landmarks and water/medic stations.
- **Race Day Schedule**:
  - Wave departure timeline from 04:30 AM to 11:30 AM.
- **Luxury Athlete Kit**:
  - Technical Race Jersey, Plantable Seed Bib, ChronoTrack RFID Chip, Heavy Cast Finisher Medal, Recovery Pack, and Digital Passport.
- **Archival Photo Gallery**:
  - Responsive masonry grid with an interactive full-screen Lightbox and keyboard navigation.
- **Interactive 3-Step Registration Portal**:
  - Step 1: Athlete Details & Emergency Contact.
  - Step 2: Race Category, Bib Name, & Jersey Size.
  - Step 3: Review, Terms & Medical Waiver, Instant Bib Number Generation, and Confetti celebration.
- **FAQ Accordion**:
  - Bib expo collection dates, age criteria, cutoff timings, and medical provisions.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.react.dev/)
- **Effects**: [canvas-confetti](https://www.npmjs.com/package/canvas-confetti)
- **Form Validation**: [Zod](https://zod.dev/)

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run local development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm start
```
